## What the notebook covers

A vehicle routing problem (VRP) for appliance delivery, solved with ArcGIS
network analysis tools from the ArcGIS API for Python. It is a reference for
understanding route optimization workflows, not a project of mine.

## Running it

The notebook requires an ArcGIS Online or ArcGIS Enterprise account and the
`arcgis` Python package. Follow the setup notes in the original Esri repository.
